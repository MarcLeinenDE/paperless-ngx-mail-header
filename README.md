# Paperless-ngx Mail Header

An unofficial Paperless-ngx parser extension that adds sender, recipient, date and subject above HTML email content in the generated PDF.

The initial `0.2.0` source import is being reviewed in a pull request. It preserves the runtime logic of the maintainer's production `0.1.0` package. Full usage, compatibility evidence, tests and installation documentation are included in that import.
